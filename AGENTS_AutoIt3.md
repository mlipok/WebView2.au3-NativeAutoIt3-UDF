# AutoIt3 instructions

For work on AutoIt source files, read and apply `AGENTS_AutoIt3_rules.md` after reading the main `AGENTS.md`. The main `AGENTS.md` defines the permitted scope and takes precedence if instructions conflict. `AGENTS_AutoIt3_rules.md` is the authoritative English version of the extracted AutoIt rules.

Whenever `AGENTS_AutoIt3_rules.md` changes, update its complete Polish translation in `AGENTS_AutoIt3_reguły.md` as part of the same task. Keep the sections and examples aligned; do not leave a partial or outdated translation. This is a required step for each change to the English rules, not a background translation service.

Whenever this `AGENTS_AutoIt3.md` file changes, update its complete Polish translation in `AGENTS_AutoIt3_PL.md` as part of the same task. Keep both instruction files aligned. The English file is authoritative if their wording differs.
