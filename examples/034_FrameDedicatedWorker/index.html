Dedicated worker from an iframe

The AutoIt operation log on the left records native worker events and JSON messages.

How to interpret the results

After Terminate worker, the iframe reports that its worker ended. If you then click Send JSON to worker, the UDF rejects the message because that worker ID is no longer valid. This is the expected result, not a new failure.

The iframe's earlier ping reply shows that its own JavaScript exchanged a message with the worker. To verify the UDF's new direct JSON channel, look in the AutoIt operation log for the earlier worker reply containing "sum":5 for [2,3]. A later rejection alone does not prove that exchange.
