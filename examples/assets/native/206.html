Native file downloads

The AutoIt host decides whether to allow or deny each download, chooses a destination, and receives native progress and state events.

Use Download ZIP or Deny next ZIP in the AutoIt toolbar. Choose destination defers the start decision, then opens a native file dialog outside the WebView2 callback. Use Pause, Resume, or Cancel current while a transfer is active.

This download needs an internet connection. The separate AutoIt --smoke modes generate a local file and need no internet.
