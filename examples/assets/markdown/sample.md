# Markdown Viewer

Live **preview** with an always-expanded table of contents. Unicode sample: ąćęłńóśźż 😀.

## Getting started

### Open a document

Open an existing Markdown file or pass its path as the first command-line argument.

### Edit and preview

Type in the editor to update the preview. Click any heading in the contents tree to jump to its section.

## Export

### PDF

Use the PDF button to save a printable document. The contents sidebar is hidden when printing.

### MHTML

Use the MHTML button to save the page as a web archive.
