Dedicated workers from a page and an iframe

The main document has no worker.

Test procedure

Click Create page worker and Create frame worker. The AutoIt log should report frame ID 0 for the page worker and a positive ID for the iframe worker.

Click Spawn page child and Spawn frame child. Each child worker is created by its parent worker, not by the page or iframe. List hierarchy shows their native UDF IDs and immediate parent IDs. Send JSON should produce two replies with "sum":7. Stop roots invalidates the tracked worker IDs.

A dedicated worker runs JavaScript in a separate browser context. WebView2 raises a different creation event on the main document, an iframe, and a worker. The UDF combines these events while retaining each worker's owner and lifetime.
