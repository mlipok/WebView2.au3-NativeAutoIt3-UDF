# AutoIt 3 local installation

Use the local AutoIt installation at `Z:\AutoItPortable\`:

- AutoIt (32-bit): `Z:\AutoItPortable\App\AutoIt3.exe`.
- AutoIt (64-bit): `Z:\AutoItPortable\App\AutoIt3_x64.exe`.
- Aut2Exe (32-bit): `Z:\AutoItPortable\App\Aut2Exe\Aut2exe.exe`.
- Aut2Exe (64-bit): `Z:\AutoItPortable\App\Aut2Exe\Aut2exe_x64.exe`.
- Au3Check: `Z:\AutoItPortable\App\Au3Check.exe`.
- Tidy: `Z:\AutoItPortable\App\SciTE\Tidy\Tidy.exe`.
- AU3Stripper: `Z:\AutoItPortable\App\SciTE\au3Stripper\AU3Stripper.exe`.
- AutoIt3Wrapper: `Z:\AutoItPortable\App\SciTE\AutoIt3Wrapper\AutoIt3Wrapper.exe`.

Follow `AGENTS_AutoIt3_rules.md` for validation and safe invocation.
